# Water Tank Problem Calculator

## Project Overview

The Water Tank Problem Calculator is a simple web-based application developed using HTML, CSS, and JavaScript. It provides a user-friendly interface for working with water tank-related calculations.

The application demonstrates basic frontend development concepts, including user input, interactive controls, styling, and JavaScript-based calculations.

## Features

- Simple and user-friendly interface.
- Input fields for entering values.
- Interactive buttons to perform calculations.
- JavaScript-based calculation logic.
- Responsive viewport configuration for different screen sizes.
- Clean layout with custom colors and styling.

## Technologies Used

- **HTML5** – Structures the web page.
- **CSS3** – Styles the interface, colors, spacing, and layout.
- **JavaScript** – Handles user interactions and calculation logic.

## Project Structure

```text
water_tank/
└── index.html
```

The HTML file contains the page structure, CSS styling, and JavaScript functionality.

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click the file and select **Open with Live Server**, if the Live Server extension is installed.

Alternatively, double-click `index.html` to open it in your web browser.
